# ピンボールメーカー / Pinball Maker

**[English README](README.en.md)**

ブラウザだけで **自分だけのピンボールゲーム** を作って、**1つのHTMLファイル** として書き出せるツールです。
書き出したゲームはスマホでもPCでも、ファイルを開くだけで遊べます。インストールもサーバーも不要です。

Copyright © 2026 FUJIYAMA2236 — [MIT License](LICENSE)

## 言語（日本語 / English）

- **エディタ**：右上の「English / 日本語」ボタンで切り替えられます。初回はブラウザの言語に合わせて自動で選ばれ、選んだ言語は次回も保たれます
- **書き出したゲーム**：テーブル設定の「ゲーム画面の言語」で、**自動（遊ぶ人のブラウザの言語）** / 日本語 / English を選べます。テストプレイでは「自動」のときエディタの表示言語で表示します

## はじめかた

1. `index.html` をダブルクリック（Chrome / Edge / Safari / Firefox）
2. 最初に出てくる画面で **ひな形** を選ぶ
3. 左の「パーツ」をテーブルへドラッグして置く・消す・動かす
4. **▶ テストプレイ** ですぐ遊んで確認
5. **HTML書き出し** で完成！

作品はブラウザに自動保存されます。別のPCへ持っていくときは「保存」で `.pinball.json` ファイルにしてください。

## エディタの操作

| 操作 | やり方 |
|---|---|
| パーツを置く | 左のパーツをテーブルへドラッグ（クリックすると画面の真ん中に追加） |
| 移動 | パーツをドラッグ（`Alt` を押しながらだとマス目に吸着しない） |
| 形・大きさ・向きを変える | 選ぶと出る白い **●■◆** ハンドルをドラッグ |
| 細かい設定 | 右のパネル（色・得点・強さなど）。何も選んでいないときはテーブル全体の設定 |
| 左右対称に作る | `M` キー or「左右反転コピー」。ピンクの点線が対称軸 |
| 範囲選択 | 何もない所をドラッグ／`Shift`+クリックで追加 |
| 重なったパーツを選ぶ | 同じ場所をもう一度クリック |
| メニュー | 右クリック（タッチなら長押し） |
| 拡大縮小・移動 | ホイール／2本指ピンチ、`Space`+ドラッグ・右ドラッグ |
| 削除・複製 | `Delete`、`Ctrl+D` |
| 元に戻す・やり直し | `Ctrl+Z`、`Ctrl+Y` |
| コピー・貼り付け | `Ctrl+C`、`Ctrl+V` |
| テストプレイ | `Ctrl+Enter`（スマホ表示／PC表示を切り替え可） |

タブレットやスマホでもエディタを使えます（タッチでドラッグ、2本指でズーム）。

## パーツ一覧

| パーツ | 役割 |
|---|---|
| 壁 / カーブ壁 | ボールがはね返る壁。両端（カーブは真ん中の◆も）をドラッグして形を作る |
| ポスト | 小さな丸いゴムの柱 |
| ゲート（ワンウェイゲート） | 矢印の向きにだけボールを通す。発射レーンの出口などに |
| バンパー | 当たるとボールを強くはじく |
| スリング（スリングショット） | 三角形のはじき台。白いゴムの面でボールをはじく |
| ターゲット | 当てると光る。同じグループを全部光らせるとボーナス |
| ドロップ（ドロップターゲット） | 当てると倒れる。同じグループを全部倒すとボーナス＆復活 |
| ロールオーバー | 通過すると点灯。同じグループ全部点灯で **得点倍率アップ**（最大×5） |
| ホール | ボールを捕まえて、矢印の向きへ打ち出す |
| フリッパー | プレイヤーが操作する板。「左」「右」どちらのボタンで動くか選べる（上段に置いてもOK） |
| 発射台 | ボールが出てくる場所（1つだけ） |
| 文字 / 飾りライト | 見た目だけの飾り（当たり判定なし） |

テーブル全体の設定では、テーマ（ワンタッチ配色）、背景の模様、ボールの数、ボールセーブ（発射直後に落ちたら1回戻る）、重力、ボールの大きさ、ゲーム画面の言語を変えられます。
右パネルの「チェック」に、発射台やフリッパーがない等の注意が表示されます。

### 背景画像

テーブル設定の「背景画像 → 画像を選ぶ…」、または画像ファイルをエディタのウィンドウへドロップすると、好きな画像をテーブルの背景にできます。

- **表示する範囲**：「枠の内側だけ」（初期設定）は、壁・カーブ壁・フリッパーで囲まれた台の内側を自動で見つけ、はみ出した部分を切り取ります。外枠の形を変えると表示範囲も自動で追従します。「テーブル全体」は四角いテーブル全面に表示します
- **合わせ方**：すき間なく / 画像全体 / 引き伸ばし（「枠の内側」の大きさが基準）
- **位置・拡大**：「テーブル上でドラッグして調整」を押すと、テーブル上のドラッグで画像を移動、ホイール（タッチなら2本指ピンチ）で拡大縮小できます。調整中は枠の外にはみ出した部分が薄く表示されます。スライダーで数値調整、「リセット」で元に戻せます
- **画像の濃さ**：下げると背景色と混ざって暗くなり、パーツが見やすくなります
- 画像はテーブルに必要な大きさまで自動で縮小され、作品ファイルと書き出しHTMLの中に埋め込まれます（別ファイルは不要）
- 外枠の壁にすき間があって囲まれていないときは、テーブル全体に表示されます

### 台揺らし・TILT

ゲーム中に台を揺らしてボールの軌道を変えられます。ただし短い間に何度も揺らすと「WARNING」→「DANGER」と警告が出て、回数を超えると **TILT**。
TILT するとフリッパーが止まり、得点も入らなくなり、そのボールを失います（ボールセーブも効きません）。警告は次のボールでリセットされます。

テーブル設定の「台揺らし・TILT」で、揺らしのオン/オフ、スマホを振って揺らせるか、TILT のオン/オフ、TILT までの警告回数（0〜5）を変えられます。

## 書き出したゲームの操作

| | スマホ | PC |
|---|---|---|
| 左フリッパー | 画面の左半分をタップ | `Z` / `←` / 左`Shift` |
| 右フリッパー | 画面の右半分をタップ | `/` / `→` / 右`Shift` |
| 発射 | 画面を長押し → 離す（長いほど強い） | `Space` / `↓` を押して離す |
| 台を揺らす | 指で上へサッとはらう（はらった向きに押す）／スマホを振る | `↑` / `W`（`Q`・`E` で斜め） |
| 一時停止 | 右上の ❚❚ | `P` / `Esc` |

※ iPhone でスマホを振って揺らすには、スタート時に出る「モーションへのアクセス」を許可してください（許可しなくても、はらう操作で揺らせます）。

左右同時押し（マルチタッチ）、効果音（♪で切替）、振動（対応端末）、全画面ボタン（対応ブラウザ）、ハイスコア保存に対応しています。縦画面・横画面のどちらでも自動でレイアウトします。

## スマホで遊んでもらうには

- 書き出した `.html` を Web に置く（GitHub Pages、Netlify Drop など）と、URLを送るだけで誰でも遊べます
- ファイルを直接スマホに送り、ブラウザで開いても遊べます
- 書き出したHTMLはエディタの「開く」で読み込めるので、あとから再編集もできます

## ファイル構成

```
index.html              エディタ本体（これを開く）
css/editor.css          エディタの見た目
js/engine.js            ゲームエンジン（物理演算・描画・タッチ操作・効果音）
js/editor.js            エディタ（パーツ配置・ハンドル・設定パネル・書き出し）
js/templates.js         ひな形とサンプルのデータ
samples/                サンプルゲームとプロジェクト
tools/build-samples.js  samples/ を作り直す（node tools/build-samples.js）
tools/build-single.js   エディタ一式を1つのHTMLにまとめる（node tools/build-single.js → dist/pinball-maker.html）
LICENSE                 MITライセンス（Copyright © 2026 FUJIYAMA2236）
THIRD-PARTY-NOTICES.md  外部ライブラリ・素材についての表記（同梱なし）
README.en.md            英語版 README
```

書き出しHTMLには `js/engine.js` のエンジン関数と、テーブルのデータ（JSON）がそのまま埋め込まれます。
外部ファイルや通信は使わないので、オフラインでも動きます。

## プロジェクトファイル（.pinball.json）の形

```json
{
  "format": "pinball-maker",
  "version": 1,
  "title": "MY PINBALL",
  "table": { "width": 560, "height": 1000, "mirrorX": 260, "balls": 3,
             "bgImage": "data:image/jpeg;base64,...", "bgFit": "cover", "bgAlpha": 0.8,
             "bgArea": "frame", "bgZoom": 1, "bgX": 0, "bgY": 0,
             "nudge": true, "shake": true, "tilt": true, "tiltWarnings": 2, "lang": "auto", "...": "..." },
  "objects": [
    { "id": "o1", "type": "bumper", "x": 200, "y": 232, "r": 28, "color": "#ff3d81", "score": 100, "power": 620 },
    { "id": "o2", "type": "wall", "x1": 8, "y1": 190, "x2": 8, "y2": 1000, "thick": 5, "color": "", "bounce": 0.45 }
  ]
}
```

座標はテーブル左上が (0, 0)、下に行くほど y が大きくなります。足りない項目は自動で初期値が入ります。
